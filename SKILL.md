# Master Workflow

1. Define the requested deliverable, audience, format, environment, and acceptance criteria. Answer simple questions directly. Ask only about material ambiguities or missing prerequisites.
2. Inspect the source files, repository, footage, or design. Confirm scope and authorization before editing or taking external actions. Check current primary documentation when the task depends on changing product facts.
3. Choose one lead playbook from the table. Use related skills only when they help deliver the requested outcome. Read the selected reference before using outside tools.
4. Produce the artifact within scope. Preserve original footage and data. Follow project conventions, keep credentials out of artifacts, and distinguish provider-dependent steps from work that can run locally.
5. Verify the normal user path and relevant edge cases. Give the deliverable, evidence of what ran, and any remaining dependency. Label unrun tests, simulated visuals, and outputs awaiting production.
