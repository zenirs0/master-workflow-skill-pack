# Release checklist

- [ ] Verify target project, branch, environment, and deployment authorization.
- [ ] Run the project’s lint, type, test, migration, and build checks as applicable.
- [ ] Confirm public URLs, callback URLs, environment variables, and server-side secrets.
- [ ] Test the main user path and failure states in the preview.
- [ ] Check accessibility, mobile layout, browser errors, and basic performance.
- [ ] Record the restore or rollback procedure if the release affects live users or data.
- [ ] Verify the deployed URL and main user path after release.
