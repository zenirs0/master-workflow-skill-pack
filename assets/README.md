# Included practice media

| Asset | Purpose |
|---|---|
| [sample-video.mp4](sample-video.mp4) | Six-second synthetic test pattern with color changes and a tone. Use it to check imports, cuts, reframing, and audio. |
| [sample-cover.png](sample-cover.png) | First frame of the sample video for preview and cover tests. |
| [sample-captions.srt](sample-captions.srt) | Three timed subtitle cues for caption import and sync tests. |
| [sample-edit.csv](../examples/sample-edit.csv) | An example edit timeline that uses the included sample. |

Regenerate the original media with `python scripts/media_smoke.py --regenerate` from the repository root. Replace the fixture with authorized project footage for an actual video.
