# Dependencies and access

| Workflow | Included here | Needed for live execution |
|---|---|---|
| Plan, draft, research from provided files | Markdown playbooks, prompts, templates, examples | An assistant that can read the pack, plus web access if external research is requested |
| Code and test | Implementation and release templates | The actual repository, project toolchain, and any environment setup documented by that project |
| UI/UX and web design | Design brief and handoff example | Figma access for live designs, a browser for preview, project tools for implementation |
| Cloud and database deployment | Deployment playbooks and checklists | The relevant GitHub, Vercel, Hostinger, AWS, or Supabase account with authorization |
| Roblox Studio and capture | Full playbook and worked shot sequence | Roblox Studio on a supported desktop, an authorized place, Studio connection if wanted, and recording software |
| Video generation | Brief, continuity checklist, and example prompt | Provider account and model access for Veo, Runway, or fal, plus rights to uploaded media |
| Editing and captions | MP4 fixture, PNG cover frame, SRT, and edit table | Optional editor or rendering runtime such as Kdenlive, Remotion, FFmpeg, or Whisper |
| Pack validation | Standard-library Python checks | Python 3.10 or newer. FFmpeg and FFprobe for media-specific scripts |

The catalog links to upstream third-party skill and plugin sources. Each provider controls its own licensing, access, and runtime. The included playbooks, templates, and fixture run independently of those providers.

Use the [previous inventory](prior-inventory.md) to identify packages from the original account. Verify the exact listing and platform compatibility before installing anything on the new account.
