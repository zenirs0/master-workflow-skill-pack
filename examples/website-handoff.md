# Example — Responsive download landing page

**Goal** — Explain an app in one screen and let visitors open the correct store listing. Use the product’s own brand assets and copy.

| Item | Example acceptance criterion |
|---|---|
| Primary action | The download button opens the user-provided listing on mobile and desktop. |
| Responsive layout | Copy and visual stay legible at 360, 768, and 1440 CSS pixels. |
| Motion | Entrance animation settles quickly and reduced-motion users see stable content. |
| Accessibility | Keyboard focus is visible, the CTA has a clear label, and text contrast is checked. |
| Verification | Save mobile and desktop screenshots and record pass or fail for the CTA and keyboard path. |
