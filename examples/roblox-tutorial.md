# Example — 30-second Roblox coin pickup tutorial

**Task** — Show a one-time coin pickup and a server-owned score increment in a 9:16 short.

**Studio capture** — In an authorized test place, record the first pickup, score change, and a second attempted pickup. Save the relevant script and Output log. If the test does not pass, resolve the behavior before recording a result claim. Record gameplay and the code editor as separate clips.

| Time | Visual | Narration |
|---|---|---|
| 0–3 s | Gameplay proof of the score increment | “Here’s the coin pickup you’ll build.” |
| 3–9 s | Studio hierarchy with the coin and server script visible | “Keep the score update and one-time pickup state on the server.” |
| 9–19 s | Actual Luau change highlighted above gameplay | Explain how the test checks for a player and prevents a second award. |
| 19–26 s | First and second attempt side by side | Describe the observed result from Studio. |
| 26–30 s | Outcome and script location | Give the name of the script the viewer should inspect. |

For a dry run, use the included [synthetic sample](../assets/README.md). Replace it with real Studio footage before claiming a playtest result.
